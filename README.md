# Vite & Gourmand

Application web réalisée dans le cadre de l'ECF du titre professionnel Développeur Web et Web Mobile.

## Objectif

Développer une application permettant à l'entreprise Vite & Gourmand de présenter ses menus de traiteur et de gérer les commandes de ses clients.

## Stack technique envisagée

- PHP orienté objet
- Architecture MVC
- PDO
- MariaDB
- MongoDB
- HTML
- CSS
- Bootstrap
- JavaScript

## Installation locale

La procédure d'installation sera complétée progressivement au cours du développement.
